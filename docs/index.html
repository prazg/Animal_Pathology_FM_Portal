3-Step Local Backend Launch

  1. 1. Automated Setup (Windows PowerShell or Linux/macOS Bash)

    Installs Python 3.11 via Astral uv, configures backend/config.yaml, and launches FastAPI:

    powershell -ExecutionPolicy Bypass -File docs/install/setup.ps1
    bash docs/install/setup.sh
  2. 2. Optional High-Throughput vLLM Server for TissueDecision-9B
    vllm serve lighteternal/tissuedecision-9b --port 8001 --dtype bfloat16
  3. 3. HPC / Slurm Compute Node via SSH Tunnel
    sbatch backend/hpc/serve_slurm.sbatch && ssh -N -L 8000:<gpu-node>:8000 user@cluster
